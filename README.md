# bymood.

Maquette de site Architecture intérieure · Design · Rénovation.

Site : https://ethancohhh.github.io/bymood-site/

Les prestations et informations d’entreprise d’exemple restent à adapter. Les études et inspirations conservent leurs attributions. Le formulaire prépare un récapitulatif local sans transmission.

## Développement

Node.js 22 ou supérieur.

```sh
npm ci
npm run dev
npm run build
```

## Publication

GitHub Actions construit et publie automatiquement le site sur GitHub Pages à chaque push sur main. L’URL et le sous-dossier sont fournis par GitHub Pages au build.
