# bymood.

Maquette de site Architecture intérieure · Design · Rénovation.

Site : https://bymood.fr/

Les photographies avant/après présentent des prestations réalisées. Les inspirations d’aménagement et les études 3D conservent leurs statuts et attributions. Les informations d’entreprise d’exemple restent à adapter. Le formulaire prépare un récapitulatif local sans transmission.

## Développement

Node.js 22 ou supérieur.

```sh
npm ci
npm run dev
npm run build
```

## Publication

GitHub Actions construit et publie automatiquement le site sur GitHub Pages à chaque push sur main. L’URL et le sous-dossier sont fournis par GitHub Pages au build.
